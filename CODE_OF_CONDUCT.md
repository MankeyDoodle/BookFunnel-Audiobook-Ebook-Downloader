# Code of conduct

This is a small project run by one person. The rules are short.

- Be kind and assume good faith. Disagree with the code, not the person.
- No harassment, slurs, or personal attacks, in issues, pull requests or anywhere
  else the project is discussed.
- Keep reports and examples free of other people's personal information. Do not
  paste cookies, signed links, account emails or private messages.
- Stay on topic: the script, its bugs, and how to improve it.

Comments and contributions that break these rules may be edited, hidden or
removed, and repeat offenders may be blocked. To report a problem, open a
private security advisory on GitHub (Security tab, "Report a vulnerability") or
contact the maintainer through their GitHub profile.
